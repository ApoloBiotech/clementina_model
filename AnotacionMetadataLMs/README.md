## LMs anotación de metadata de Soja y Tomate. (all NCBI entries)

1. Buscar todos los IDs de SRA de fastq files
2. Generar Tabla con todos los IDs de SRA (SRRs IDs) y BioSample ->  Organism.csv
3. Usar esa tabla y correr sra.py.   El script lee un archivo CSV con metadatos, filtra los registros de RNA-Seq, elimina duplicados basándose en la columna biosample y transforma la columna attributes a un formato JSON para extraer información adicional. Luego, une esta información al DataFrame principal y guarda ambos resultados en archivos CSV para su posterior análisis. Se exporta el DataFrame final sra a un archivo CSV llamado sra.csv.
4. Luego correr biosample_runv2.py (info attributes de BioSmaple DB) :  El script carga datos SRA de muestras de tomate y procesa la información de biosample, intentando cargar atributos previamente guardados o extrayéndolos de la web con lógica de reintentos para gestionar límites de NCBI. Luego, alinea estos atributos con los IDs de biosample del archivo SRA y guarda el resultado en un archivo CSV para su análisis posterior.
5. En paralelo, buscar info de BioProject,  correr script bioproject.py: El script carga un archivo SRA de muestras  para extraer los identificadores únicos de bioproject. Luego, carga o genera atributos para cada bioproject mediante funciones del módulo bioproject_v2, añade los abstracts asociados a partir del DOI y guarda el DataFrame final en un archivo CSV para su análisis posterior.
6. En paralelo, buscar info de DB Geo; usar script  geo_v2_Updated_chunksFull.py  :   El script carga datos SRA desde un archivo CSV, extrae los IDs únicos de BioSample y los divide en bloques para procesarlos por partes. Luego, para cada BioSample, consulta la base de datos GEO mediante Entrez para obtener metadatos clave (como accession, título, resumen y enlace FTP) utilizando expresiones regulares, implementa lógica de reintentos para manejar errores y guarda progresivamente los resultados en un archivo JSON.
7.  Juntar files sra-Biosample con GEO data:    script  joinedGeo_BioSample.py   : El script carga dos archivos JSON, uno con datos de biosample y otro con metadatos GEO, y crea un diccionario para relacionar rápidamente las entradas por el identificador "BioSample". Luego, actualiza cada entrada de biosample con el "Title" y "Summary" obtenidos de GEO (si están disponibles) y guarda el resultado en un nuevo archivo JSON.
8.  Luego, juntar (merge) data de BioSample-SRA con la de Bioprojects, script joinedBioproject_SRA.py  : El script carga dos archivos CSV (uno con datos de bioproject y otro con datos SRA), filtra las columnas relevantes del SRA y fusiona ambos conjuntos de datos utilizando el identificador de bioproject. Luego, elimina columnas redundantes, verifica si faltan entradas de BioSample y exporta el resultado final a un archivo JSON para su posterior análisis.
Luego, finalmente, juntar ambos merged files:  script  join_JsonBiosample2JsonSRA.py  : El script carga dos archivos JSON (uno con datos de biosample y metadatos GEO, y otro con datos combinados de BioProject y SRA), y luego une la información de ambos conjuntos usando el identificador BioSample. Para cada muestra coincidente, agrega los atributos de BioProject (con sufijo _BioP) solo si tienen valores no vacíos, cuenta las coincidencias y finalmente guarda el resultado junto con estadísticas en un nuevo archivo JSON.
